# «Синий корт» — демо-сайт теннисного клуба

Пример для портфолио: клуб вымышленный. Статический сайт (HTML, CSS, JS), без сервера.

- `index.html` — главная
- `bron.html` — бронь корта: календарь, корты, часы, тренер или партнёр, «Мои записи»
- `raspisanie.html` — расписание групп по неделям и запись
- `trenery.html` — тренеры
- `ceny.html` — калькулятор абонемента и каталог
- `kabinet.html` — кабинет владельца (пример): добавить, изменить, скрыть, удалить абонемент; заявки
- `404.html` — страница «Мяч ушёл в аут»

Все цены и цифры считаются в `js/data.js`. Расписание может читаться из Google Таблицы (адрес CSV в `SHEET`).
Шрифт Geologica (Google Fonts, OFL). Фото — Unsplash, список в `photos.txt`.
